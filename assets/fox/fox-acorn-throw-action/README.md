# Fox Acorn Throw Action

Four transparent PNG frames for a short over-the-shoulder acorn throw animation.

- `fox_throw_acorn_01_glance_back.png`
- `fox_throw_acorn_02_windup.png`
- `fox_throw_acorn_03_release.png`
- `fox_throw_acorn_04_recover.png`

The acorn is intentionally not included in the fox frames so it can be animated as a separate projectile. All frames are 1536 x 1024 RGBA PNGs.
