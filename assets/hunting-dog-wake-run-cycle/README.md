# Hunting Dog Wake and Run Cycle

16 transparent PNG sprite frames for the Fox Runner hunting dog.

- `hunting_dog_01_sleep.png` to `hunting_dog_04_alert.png`: asleep, waking, head shake, alert.
- `hunting_dog_05_run.png` to `hunting_dog_16_run.png`: 12-frame running loop.

All frames are 1536 x 1024 RGBA PNGs with transparent backgrounds.
