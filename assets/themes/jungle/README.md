# Jungle Theme Asset Pack

This pack is the jungle set for Fox Runner. It follows the existing theme
conventions: 512x341 landscape character sprites, 341x512 portrait trees, and
transparent scenery layers except for `sky.png`.

Animals face left so the fox approaches them from the right. Numbered files are
intended to be played as reaction or movement sequences. The `ground` folder
contains the jungle floor, river, bank edge, and low/high landing platforms.
